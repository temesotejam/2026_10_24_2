# M0 基盤評価と次の実装

この文書は M0 導入時点の記録です。後続の操作改善は [M1 操作改善](M1-CONTROLS.md) を参照。

## 採用した基盤

- 出典: https://github.com/Vincent-P-essy/minecraft-clone
- 固定した上流コミット: `6766703c14f7a443d94983600528614cc931df89`
- MIT License。LICENSE の著作権表示を保持。
- Three.js / simplex-noise、TypeScript / Vite / Vitest / Puppeteer。
- ロックファイルをそのまま採用し、`npm ci` で再現。
- 本番依存への `npm audit --omit=dev` は既知の脆弱性 0 件。
- 元の `.git` は取り込まず、対象リポジトリの Git 情報を維持。

地形生成とメッシュ生成の Worker、Greedy Meshing、物理と描画の分離、
衝突判定テストがあり、M0 の開発基盤として採用しました。
第二候補は計画書に具体的な指定がないため、比較ベンチマークは実施していません。
性能上の最終選定には同一端末・Seed・視界距離での比較が必要です。

- リモートへの push、GitHub 設定変更、公開は未実施。

## ローカル検証

- 19 ファイル、216 件の単体テストが成功。
- ESLint、Prettier、TypeScript、通常ビルド、Pages ビルドが成功。
- システム Chromium と SwiftShader で Pages のサブディレクトリ配信を検証。

この環境のソフトウェア描画は実機性能の合否判定には使いません。

これはビルド失敗ではありませんが、今後の性能予算に含めます。

## 後続フェーズの制約

保存は localStorage のブロック差分のみです。容量超過時のエラー処理と破損データの
検証が不十分なため、重要な長期ワールド向けの保存基盤とは扱いません。
IndexedDB・バックアップ・プレイヤー状態保存は別フェーズで実装します。
光の伝播、道具、クラフト、体力・空腹、敵・動物は未実装です。
