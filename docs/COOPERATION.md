# 協調動作の実験モード

このモードは、軽量な自作ゲームの一つのワールドで、複数の自動プログラムの協調を試すための初期実装です。公式 Minecraft への接続や、インターネット越しの複数人接続ではありません。

`?seed=80&mode=survival&view=third-person&coop=1` を付けてゲームを開くと、２人目が現れます。ワールド、時刻、地形の変更、MOB、落としたアイテムは共有し、位置・体力・空腹・所持品は別々です。MOB は近い生存者を追跡し、攻撃できます。２人目も地形に衝突し、落下・空腹・水や火によるダメージを受けます。実験用セーブは１人用と分離され、再読み込みできます。

実験を再現するには、リポジトリで `npm install` と `npm run dev` を実行し、別のターミナルで次を実行します。Chromium が必要です。

```sh
PUPPETEER_EXECUTABLE_PATH=/usr/bin/chromium node scripts/cooperation-playtest.mjs --url http://127.0.0.1:5173/ --out /tmp/cooperation-playtest
```

このスクリプトは一時的な新規ブラウザプロファイルから開始し、別々のルールに従う２つの役割を１つの Node.js プロセスで動かします。探索役が実際に見つけた木をメッセージで伝え、採取役が移動して原木を採り、板材を作って手渡します。探索役が受け取った板材を通常の操作で設置し、両者から見えることと、セーブ・再読み込み後にワールドとそれぞれの所持品が残ることを確認します。結果は指定したフォルダの動画と `events.json` に保存されます。言語モデルや別々の AI プロセスが自律判断した記録ではありません。

## それぞれが判断して協力する実行

次の実行では、探索・建築役と採取・加工役を別々のワーカースレッドで動かします。各ワーカーは自分の観測と受信メッセージから行動を決め、相手の操作を直接指定できません。役割は開始時に決め、苗木の確保と植え付け、木の発見、採掘、拾得、加工、受け渡し、双方の設置を実際の状態に応じて進めます。上方に育つための空間がある場所に苗木を植えてから原木を使い、苗木を確保できなければ作業を停止します。

苗木を探す間は両者が別の葉を並行して調べ、対象をメッセージで知らせます。１人目の採掘中に照準が別のブロックへ変わった場合は操作を中止し、２人目が苗木を植える際は１人目の採掘終了を待ちます。２人目の腕は１人目のクリックではなく、本人の採掘・攻撃に合わせて動きます。移動はゲーム本来の歩行速度で、短い操作ごとの余分な固定待機を減らしています。

各判断前に敵と時刻を確認します。近くに敵がいる場合は作業を止めます。日暮れが近く２台のベッドが見える場合は、それぞれ別のベッドを担当して夜に眠る手順を試みます。ベッドや安全な道が足りない場合は停止します。足場と頭上の空間を確認し、既知の地形で１ブロックの上り下りを含む経路を探します。木を遮る葉は必要な範囲で取り除きます。

```sh
PUPPETEER_EXECUTABLE_PATH=/usr/bin/chromium npm run coop:agents -- --url http://127.0.0.1:5173/ --seed 80 --out /tmp/cooperative-agents
```

`events.json` に各ワーカーの観測、メッセージ、行動と結果、完了または停止の理由を記録します。録画も出力します。これは別々の判断ループを持つルールベースの自動プログラムであり、言語モデルを使った自律判断ではありません。ブラウザ操作を仲介する１つのプロセス内で実行し、独立した端末や安全な隔離環境ではありません。

`--require-overlap` を付けると、２人が異なる対象を同時に採掘していたことを記録から確認します。地形やアイテムの出現により、すべての試行で重なりが発生するとは限りません。

Seed 92 の新規サバイバルワールドでの各１回の試行では、最初の観測から課題完了までのゲーム内経過時間が、以前の約15.4秒から並行作業後の約6.9秒になりました。苗木の植え付けと２人の作業完了を確認し、２人とも体力20でした。役割分担やドロップの順番が変わるため、これは全地形で同じ短縮率になるという意味ではありません。

就寝時の役割分担と時間の進行は自動テストで検証していますが、自然なワールドで２人が実際に一晩を過ごす実演はまだありません。村に初めからあるベッドは１台で、もう１台を作る行動も未対応です。苗木を植えても、長期的に育成・収穫を繰り返せることまでは確認していません。敵の確認は各判断の前に行うため、確認と停止の間に攻撃を受ける可能性があります。初期課題は両者が板材を１個ずつ設置する短い協力作業です。地形によっては到達できず、安全停止または時間切れになることがあります。結果を上書きしないため、再実行時には新しい出力先を指定してください。

## 操作インターフェース

協力モードのブラウザには `window.__coop` があり、Puppeteer などから利用できます。１人目は通常のキーボード・マウス操作、２人目は以下の関数で操作します。ゲームは通常どおりプレイ画面を開始している間に進みます。

| 関数                                          | 内容                                                                                         |
| --------------------------------------------- | -------------------------------------------------------------------------------------------- |
| `observe("player" \| "companion")`            | 指定した人の位置、体力、空腹、所持品、24ブロック以内の相手とMOB、受信メッセージを取得        |
| `block(actor, x, y, z)`                       | 指定した人から８ブロック以内で読み込み済みのブロックを取得。それ以外は `null`                |
| `move({forward, right, jump, yaw}, seconds)`  | ２人目を物理演算で移動。指示は最大１秒で切れる                                               |
| `stop()`, `blockingLeaf(x,y,z)`               | ２人目の移動・採掘を中止、または指定した対象を遮る近くの葉を確認                             |
| `select(slot)`, `mine(x,y,z)`, `place(x,y,z)` | ２人目の持ち物選択・採掘・設置。採掘には通常の所要時間がかかり、対象までの距離と遮蔽物を確認 |
| `craft(id, table?)`, `eat()`, `attack(id)`    | ２人目の製作・食事・近接攻撃。作業台が必要なレシピは近くに実物が必要                         |
| `give(actor, slot, amount)`                   | 2.5ブロック以内の相手へ所持品を渡す。全部入らない場合は移動しない                            |
| `say(actor, text)`                            | 相手へ200文字以内のメッセージを送る                                                          |
| `sleep(x,y,z)`                                | ２人目が夜に近くの安全なベッドに入る。１人目も別の安全なベッドを使うと朝になる               |

## 現在の制約

- 実演は固定ルールであり、言語モデルとの接続はまだありません。外部モデルを組み込む場合は、観測を入力にし、返された行動をこのインターフェースへ渡す制御プログラムが別途必要です。
- ２人目の表示・操作は同じブラウザ内で行います。別端末からの通信、認証、遅延や切断の処理はありません。公開ページにアクセスした人同士が直接合流できる機能ではありません。
- 観測は距離で制限していますが、MOBの観測に視界の遮蔽は適用していません。従来の検査用 `window.__mc` にも広い観測が残るため、厳密な部分観測や不正防止を目的とした分離ではありません。メッセージも同じブラウザの共有インターフェースです。
- 地形の読み込みは１人目を中心に行うため、２人目は遠くまで単独で探索できません。ネザー・エンドへの移動、２人目の復活、チェストの直接操作は未対応です。１人目の死亡時には既存の死亡画面でワールドの更新が止まります。
- 初期実演は木材の協力作業までです。長期の食料生産、２人が実ワールドで夜を越す生活、複数回の敵との戦闘はまだ実演していません。敵の追跡・ダメージと、別々のベッドが必要な就寝条件は自動テストで検証しています。
