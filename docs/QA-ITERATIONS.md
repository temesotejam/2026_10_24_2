# 独立AIによるサバイバル・プレイ検証

操作は独立した担当AIのブラウザドライバーによるキーボード・マウス・画面UIです。判断には読み取り専用のワールド情報を使います。通常プレイの検証にテスト用セーブの読み込み、所持品の注入、テレポート、時刻・体力の直接変更は使いません。

## 第1回：既存仕様の別Seedでの開始

- Seed 11031：新規サバイバル、所持品ゼロから開始。自然生成の木へ移動し、素手で原木4個を採取し、木材・棒・作業台を作成。実際に作業台を置いて操作し、木のツルハシを作成しました。体力が残った状態で終了しています。
- 開始時、プレイヤーの正面が高い崖で、木も丘の上でした。通常の地形としては成立しますが、初期の向きとスポーン位置の選び方が三人称の見やすさと初動を悪化させていました。
- Seed 11032：新規開始と自然の木への移動を開始しましたが、並行開発中のVite HMRがページを再読込し、操作コンテキストが失われました。ゲームの不具合や完走としては扱いません。

証拠は `visual-check/qa-independent/seed-11031/` のスクリーンショット・`result.json`、同 `seed-11032/result.json` です。

## 修正

新規生成方式3では、初期位置の木の幹・樹冠を避け、正面に4ブロック分の歩行・ジャンプ可能な地形と背面にカメラの余地がある候補を選び、その開けた方向へ初期視点を向けます。生成方式1・2の従来のスポーン座標と、読み込み時の保存済みの向きは維持します。崖沿いの候補、向きの選択、複数Seedの初動経路は `src/world/spawn.test.ts` で検証しています。

## 第3回：同じSeedのスポーン比較と保存復元

修正前に崖に面していたSeed 11031を、新規ブラウザで再度開始しました。修正前の `(0.5,35,0.5)`・yaw 0 に対し、修正後は `(-7.5,35,8.5)`・yaw π/2でした。通常の前進・ジャンプ入力だけで3.777ブロック移動し、向きを変えてから通常の保存ボタンで保存・再読込しました。変更したyaw `4.388996326794897` とpitch、水平位置が保持され、新規ワールド用の向きに戻されないことも確認しました。

証拠は `visual-check/qa-independent/spawn-reload/` の3枚のスクリーンショットと `result.json` です。再実行は `node scripts/spawn-reload-check.mjs` で行えます。

## 今回の独立プレイで確認していない範囲

この担当の通常プレイは序盤の採取・作成・移動・村・保存復元までです。新仕様で黒曜石を採取し、枠を自作してネザーへ入り、エンドで討伐する全工程を完走したとは主張しません。他担当の検証用データによる試験も、この通常プレイの実績には含めません。レシピ・ドロップ・ゲート連結などの単体試験やソース確認は、通常のサバイバル・プレイとは区別しています。

## 素材担当による別の改善サイクル

別の独立AI担当は、修正前に空の所持品から木・石・鉄・自然のダイヤまで通常操作で進め、UI上で丸石から火打石を作れることを再現しました。[修正前の記録](qa/progression-before.json) を残しています。

修正後は新規方式3の別プロファイルで、自然に生成された砂利へ歩き、素手で採掘して火打石1個と砂利12個を取得しました。体力20、ブラウザエラー0で、丸石→火打石・羊毛→糸・麦/木→本のレシピボタンがないことも確認しました。[修正後の記録](qa/progression-after.json)。最初の試行はボットの着地・照準が間に合わず採掘を始められず、観察を追加し、着地後に350ms待つ操作に直して再プレイしています。ゲームの素材を直接書き換えたわけではありません。

この担当も新仕様のネザー・エンドを通常プレイで完走したとは扱いません。戦闘担当による別の通常プレイと後半試験は [戦闘の再プレイ記録](AI-COMBAT-PLAYTEST.md) を参照してください。
