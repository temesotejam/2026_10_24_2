# M1 操作改善（第1段階）

現在の実装・検証は [進捗記録](STATUS.md) を参照。この文書は初期導入時点の記録です。

## 実装した挙動

- 左右の Ctrl でダッシュ、左右の Shift でしゃがみ。
- しゃがみ速度は歩行の 30%。Ctrl と Shift を同時に押した場合はしゃがみを優先。
- 視点高さは通常 1.62 ブロック、しゃがみ中は 1.42 ブロック。
- 古い操作感を参考に、当たり判定は高さ 1.8、幅 0.6 のまま維持。
  しゃがんでも低い隙間には入れません。
- 地上でしゃがんでいる間は足元の支持面を確認し、端へ出る移動を制限。
  足の一部がブロックに乗る位置までは移動可能です。
- 斜め移動は X 軸・Z 軸それぞれと組合せを調べ、角でのすり抜けを防止。
- ジャンプ中・空中・水中には端落下防止を適用しません。
  足元を採掘した場合も空中には留まりません。
- 物理計算を 120 Hz に固定。描画フレームの経過時間を蓄積して処理します。
  長い停止後は最大 0.25 秒分だけ追いつき処理を行い、大きな移動を抑えます。
- メニュー中の移動キーを無視し、一時停止・フォーカス喪失でキーボードと
  タッチの外部入力を消去します。再開には開始ボタンが必要です。
  遅れて届いたマウス固定の拒否やタイムアウトで、停止が解除されることも防ぎます。

歩行速度・重力・ジャンプ初速は既存値を維持しています。
描画補間や視点の揺れ、加減速の忠実化はまだ行っていません。

## 検証

単体テストは合計 239 件（従来 216 件 + 追加 23 件）。

- 30 / 60 / 144 FPS の模擬フレームで、2 秒間の移動距離・ジャンプ頂点・着地時刻が一致。
- 不規則なフレーム間隔、停止後の追いつき制限、一時停止時の端数時間破棄。
- 終端速度で落下中に描画が遅れても、1 ブロック厚の床を通り抜けないこと。
- 孤立したブロックの 8 方向の端、斜めの角、壁との衝突。
- しゃがみ解除後の落下、ジャンプによる端の離脱、支持ブロック除去後の落下。
- 左右 Ctrl / Shift の入力、しゃがみ時の視点、Esc とフォーカス喪失時の入力解除。

ブラウザハーネスには実際の Shift キー押下・解除による視点高さの確認を追加し、25 項目が成功。
既存の移動・採掘・設置と代替描画・タッチ操作も合わせて再検証。
端末上の操作感、実測 FPS、長時間プレイの評価は別途必要です。
