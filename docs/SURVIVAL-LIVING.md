# 村での生活プレイ

この記録は、討伐後のサバイバルセーブをコピーし、既存の村で生活を試したものです。`scripts/missions/phase-8.2.mjs` 以降の生活用スクリプトは、このセーブの村・畑・ベッドの座標を前提とした実験用の操作手順であり、任意のワールドに対応する自動プレイヤーではありません。実際のキー・マウス操作で収穫、植え直し、取引、就寝を行い、周囲の敵や対象ブロックを確認しています。

- 明るいうちに畑を手入れし、収穫した耕地に種を植え直します。食料の備蓄と苗木の植え直しに必要な種や苗木を残します。
- 釣りと村人との交換で食料を補充できますが、釣り竿には耐久力があり、魚を集める時間も必要です。
- 日暮れ前に寝床の近くへ戻り、夜はベッドを使います。敵が近づいた場合などは、安全確認のため手順を停止します。
- 木を伐採する前に植え直し用と予備の苗木を確保し、育てた木材の一部から作った斧を次の収穫に使います。苗木の生育には待ち時間が必要です。

試行中には、種の植え残しと、木の周囲の土を移動中に壊す問題がありました。耕地を確認して植え直し、段差をジャンプで越える操作に修正しています。追加の畑作業では対象の照準確認で停止したほか、移動中にツルハシが消耗する場面があったため、安全や資源節約が常に保証されるわけではありません。
