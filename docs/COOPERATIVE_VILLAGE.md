# ２人の村づくりの記録

以前のサバイバル生活のセーブをコピーし、協力モードの別セーブとして続けた。元のセーブを変更せず、既存の村・畑の近くに２つの小さな住まいを追加した。材料はセーブに残っていた物を２人で分け、糸と板材からベッドを作った。初めて迎えた夜は、既存のベッドと新たに作ったベッドを使い、２人で実際に眠って朝を迎えた。

## 場所の選び方と結果

近隣を調べ、平らで草地が続き、作物や水に重ならない４×３ブロックの区画を候補とした。既存の村や出発位置までの距離も見て、既存の建物の近く（198, 35, -72）と畑の近く（205, 35, -83）に建てた。もう１つの候補（205, 34, -62）は経路で足踏みしたため、別の区画を使った。これは調査した範囲の候補を比べた結果で、ワールド全域で最適な場所を証明したものではない。

各住まいは、ベッド、床１マスの立ち場所、２ブロックの高さの入口、丸石の壁と屋根を持つ。完成後のセーブから、２軒とも設計した壁と屋根が揃っていること、入口と入口外の足場が空いていることを確認した。２軒目は実際に中へ入り、外へ出る操作も試した。２人の体力はともに20だった。

作業中には、足場の端での経路探索、既存の家の段差、建築中の立ち位置によって壁に挟まる問題が発生した。移動経路を保持し、別の方向から作業するとともに、通常の採掘操作で土を少し取り除いて解消した。２軒目の入口外も土を掘り、地形に塞がれていた通路を開けた。

このゲームには開閉できるドアがまだないため、入口は開いたまま。家を作っただけで夜の敵を完全に防げるわけではない。村人の定住や、村としての機能が自動で増えることも確認していない。

## 実行について

`scripts/village-prepare.mjs` と `scripts/village-build.mjs` は今回のセーブと座標を対象にした実験用スクリプトで、任意の新規ワールドで村が自動完成する汎用機能ではない。建築では２つの worker がそれぞれの行動を決め、同じサバイバル世界の通常操作に接続する。採掘による脱出と入口の整地は今回、途中で個別に操作したため、この２スクリプトだけで無人のまま同じ完成結果まで再現できる保証はない。

建築対象のセーブと録画は実行環境の `artifacts/village-coop/` に保存し、リポジトリには含めていない。結果の録画は一部の作業を抜粋したもので、整地など録画していない操作も含む。

`voxel-2026-survival.json` はゲームのバックアップ機能で書き出した協力モード用セーブ。協力モードを開き、「読み込み」からこの JSON を選ぶと取り込める。同じ Seed の保存を置き換える確認が表示され、従来の保存は前回分として残る。独立したブラウザで実際に読み込み、２軒のベッドと屋根、２人の体力を確認した。
